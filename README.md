# 图解手记 · Illustrated Notes

把不同领域的学习资料，整理成讲得清楚、带有手写批注的知识手账。

## 特点

- 完整短段落：理解知识之间的关系，而不只记住关键词。
- 有信息价值的批注：释义、提问、辨析和提醒。
- 场景插画与彩色划词：内容与视觉共同组织阅读。
- 适配不同主题：按内容选择流程、对比、拆解或原理解释。

## 使用

将 `skills/illustrated-notes` 放入你使用的工具支持的 Skills 目录；实际识别方式取决于宿主。需要出图时，宿主还需具备图像生成能力。

示例指令：

> 使用 $illustrated-notes，把我提供的资料做成知识手账。读者是新手，页数按内容决定，风格参考附件，交付完整图片和简短配文。

也可以直接将 SKILL.md 的规则作为提示词使用。

## 示例与适用范围

最初来自一组医药职业分享笔记；该主题用于展示风格，不限制适用领域。示例人物、品牌与事实不属于默认模板。
当前版本已做结构校验，尚未完成多主题实际出图测试。
